J.A.T.C Cuisine ATL — Website Demo

This is a static HTML/CSS/JavaScript website. It does not require a server, database, Node.js, or a paid website builder.

FILES
- index.html = page content
- style.css = design
- script.js = mobile menu + year
- images/ = place for approved restaurant images

IMPORTANT BEFORE SHOWING THE SITE AS FINAL
1. Confirm the restaurant approves its name, description, menu, hours, phone number and address.
2. Replace demo copy and any placeholder content.
3. Only use photos/logos that the restaurant gives you permission to use.
4. Add the restaurant's approved menu/order link.
5. Test every button and link.

FREE PREVIEW
You can open index.html in a browser to preview the site.
You can also publish static files with a free static-site service such as GitHub Pages.

HANDOFF
The client can receive this whole folder as a ZIP and choose their own hosting provider/domain.
