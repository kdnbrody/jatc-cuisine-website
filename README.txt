J.A.T.C Cuisine ATL website demo

The menu has been entered from the screenshots supplied in the conversation and is organized into clickable categories.

Files:
index.html = page structure
style.css = design
script.js = menu data and category buttons
images/ = place for approved photos/logo

To change menu information, edit script.js, save it, and upload the updated file to GitHub.

IMPORTANT: Confirm all menu items, prices, descriptions, hours, phone number, address, photos, and other content with the restaurant before using this as a final client website.
